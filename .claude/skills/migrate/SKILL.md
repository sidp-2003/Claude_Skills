name: migrate
description: Migrates the fetched data stored in ".claude/skills/fetchAPI/data" directory to a new location. Use when you want to move your data to different directory
- - - 

### Usage

### Step-1: Pick the python environment
Before you start, make sure you have the correct python environment activated where you have the necessary dependencies installed.

### Step-2: Run the python script to migrate the data.
You need to run the python script made in the .claude/skills/migrate/scripts directory.


### Step-3: Verify the migration
After running the scripts, you can verify that the data has been successfully moved to the new location by checking the ".claude/skills/migrate/data" directory. You should see all your data files there.
